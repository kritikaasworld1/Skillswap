 SkillSwap

"Connecting learners, sharing knowledge, and building communities"

SkillSwap is a web-based platform designed to help users exchange skills and learn from one another. The platform allows individuals to connect with people who possess skills they wish to learn while sharing their own expertise with others. Through search, matchmaking, messaging, notifications, and session scheduling, SkillSwap creates an engaging environment for collaborative learning.

## My Contribution – Search, Matchmaking & Notifications

As part of the Agile Dynamics team, I developed the Search, Matchmaking and Notification functionality of the SkillSwap platform.

This module enables users to:

* Search for users based on skills and interests
* Discover suitable learning partners
* Browse user profiles and skill information
* Identify users with matching requirements
* Receive notifications about skill swap requests
* Get updates on accepted or rejected requests
